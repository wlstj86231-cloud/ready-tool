같은 파일인지 확인

파일마다 내용으로 계산한 파일 지문(SHA-256)이 있습니다. 내용이 한 글자, 한 점이라도 바뀌면 지문이 완전히 달라집니다. 예전에 묶어 둔 증빙과 지금 가진 파일이 같은 파일인지 확인할 때 씁니다.

파일은 이 기기 밖으로 나가지 않습니다. 지문 계산은 브라우저 안에서만 합니다.

A증빙 목록과 대조하기

거래 증빙 사진 묶음 만들기에서 받은 00_증빙목록.csv(또는 TXT)를 넣고, 지금 가진 사진·서류를 넣으면 목록의 어떤 파일과 같은지 알려 드립니다.

B두 파일 비교하기

보낸 파일과 받은 파일, 휴대폰의 원본과 컴퓨터의 사본처럼 두 파일이 완전히 같은지 봅니다.

결과를 이렇게 읽으세요

지문이 같으면

두 파일의 내용이 완전히 같다는 뜻입니다. 파일 이름이나 저장된 날짜가 달라도 내용이 같으면 지문은 같습니다.

지문이 다르면

내용이 조금이라도 다릅니다. 사진을 메신저로 보내거나 크기를 줄이거나 편집하면 새 파일이 되어 지문이 달라집니다. 그래서 원본을 따로 보관하는 것이 중요합니다.

지문이 증명하지 않는 것

지문은 "같은 파일인지"만 알려 줍니다. 사진을 언제 찍었는지, 사진 속 내용이 사실인지, 누가 만들었는지는 알려 주지 않습니다.

목록은 따로 보관하세요

증빙 목록 파일을 묶음과 다른 곳(이메일로 자신에게 보내기, 다른 저장장치 등)에도 두면, 나중에 목록과 파일을 대조할 때 믿을 만한 기준이 됩니다.

함께 읽으면 좋은 안내

  • 거래 마무리 전 최종 증빙 점검표
  • 사진 촬영 날짜 확인하는 법과 한계
