# 거래 증빙 도우미 (goatool.com)

Browser-only tools and guides for the evidence a Korean farm trade needs: what to photograph and keep when selling used machinery, shipping produce, and settling direct sales. Files never leave the browser. Operated by 제이 미디어(J MEDIA), the operator of 보리장터.

## Pages

- `/` — home (`index.html`)
- `/tools/<name>/` — tools (`tools/<name>/index.html` + `src/tools/<name>.js`):
  `evidence-pack` (core: per-trade checklists, EXIF dates, naming, ZIP/print/photo PDF),
  `photo-rename`, `pdf-organizer`, `image-redactor`, `settlement-csv`, `hash-compare`
- `/agri/guides/` — guides, generated by `scripts/generate-agri-guides.mjs` into `public/agri/guides/`
- `/about/`, `/privacy/`, `/terms/`, `/contact/`, `404.html` — generated by `scripts/generate-info-pages.mjs`
- `/mn/` — Mongolian evidence tools (static, `public/mn/`)

Shared header/footer/head live in `scripts/site-shell.mjs` (used by `vite.config.js` and the generators); styles are in `public/css/site.css`. Evidence checklists are in `src/data/presets.js` and feed both the tool and the guides.

## Build

```bash
npm install
npm run build   # generators -> vite build -> scripts/postbuild.mjs
```

`postbuild.mjs` writes `dist/sitemap.xml`, `dist/robots.txt` and `dist/_redirects` (301s for retired pages listed in `scripts/retired-routes.mjs`) and fails the build on broken internal links.

Cloudflare Pages builds from GitHub: build command `npm run build`, output `dist`.
