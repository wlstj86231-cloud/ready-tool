# 거래 증빙 도우미 (goatool.com)

Browser-only tools and guides for the evidence a Korean farm trade needs: what to photograph and keep when selling used machinery, shipping produce, and settling direct sales. Files never leave the browser. Operated by 제이 미디어(J MEDIA), the operator of 보리장터.

## Pages

- `/` — home (`index.html`)
- `/tools/<name>/` — tools (`tools/<name>/index.html` + `src/tools/<name>.js`):
  `evidence-pack` (core: per-trade checklists, EXIF dates, naming, ZIP/print/photo PDF),
  `photo-rename`, `pdf-organizer`, `image-redactor`, `settlement-csv`, `hash-compare`.
  Each page's structured data and its "이 도구에 대해" block (criteria, 범위와 한계, 출처, meta) come from `scripts/tool-info.mjs`; keep its numbers in step with the constants in `src/tools/*.js`.
- `/agri/guides/` — guides, generated by `scripts/generate-agri-guides.mjs` into `public/agri/guides/`. Every guide needs `sources` (keys from `scripts/sources.mjs`) and a `scope` (범위와 한계) list; the generator refuses to build without them.
- `/about/`, `/contact/`, `/editorial/` (편집 원칙), `/corrections/` (정정·수정 기록), `/privacy/`, `/terms/`, `404.html` — generated by `scripts/generate-info-pages.mjs`. Add an entry to its `changeLog` when a correction changes facts, numbers, legal wording or tool results.
- `/mn/` — Mongolian evidence tools (static, `public/mn/`). Mongolian is not an AdSense-supported language, so these pages are `noindex`, carry no ads and are not in the sitemap.

Shared header/footer/head, operator facts (`ORG`), the Organization/WebSite JSON-LD and the byline/meta/sources/scope blocks live in `scripts/site-shell.mjs`; styles are in `public/css/site.css` (bump `cssVersion` when it changes). Evidence checklists are in `src/data/presets.js` and feed both the tool and the guides.

Ads: the AdSense loader runs only on content pages (home, guides, about). Tool pages, legal/contact pages and the 404 use `<!--site:common:noads-->` / `ads: false`; every page keeps the `google-adsense-account` meta for site verification.

## Build

```bash
npm install
npm run build   # generators -> vite build -> scripts/postbuild.mjs
node scripts/check-c2c-howto-inbound.mjs
```

`postbuild.mjs` writes `dist/sitemap.xml`, `dist/robots.txt` and `dist/_redirects` (301s for retired pages listed in `scripts/retired-routes.mjs`), fails the build on broken internal links, and checks every sitemap page for the footer operator line and policy links, the AdSense account meta, parseable JSON-LD naming the operator, and (guides and tools) the meta block, 출처 and 범위와 한계; tool pages must not load ads and `/mn/` pages must stay noindex.

Cloudflare Pages builds from GitHub: build command `npm run build`, output `dist`.
